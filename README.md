# Relatório de Tarefas Realizadas - App Hora do Remédio

## 💡 Ideia Escolhida
**Opção B:** Gerenciar remédios para idosos com opção de compartilhar imagem da agenda do dia.

## 🛠️ Configurações e Ambiente
- Framework: Flutter
- Linguagem: Dart
- Controle de Versão: Git

## 🤖 Prompts Utilizados para Geração/Suporte
1. "Crie uma interface simples em Flutter para listagem de remédios com horários voltada para idosos."
2. "Adicione um botão flutuante para simular o compartilhamento da lista via WhatsApp."

## 💻 Programação Realizada
- Estruturação do layout limpo utilizando `ListView.builder` e `Card`.
- Implementação de dados estáticos para exibição imediata da rotina diária de medicamentos.
- Criação de uma função nativa simulada de compartilhamento usando `SnackBar` para evitar quebras de dependências externas.
